# Persistencia

Esta ubicación contiene los repositorios que se comunican con la persistencia.

## ```UsuarioDAO```

Esta interfaz contendrá las consultas necesarias para conseguir los datos de los usuarios de la base de datos.

## ```InmuebleDAO```

Esta interfaz contendrá las consultas necesarias para conseguir los datos de los inmuebles de la base de datos.

##  ```ListaDeseosDAO```

Esta interfaz contendrá las consultas necesarias para conseguir los datos de las listas de deseos de un usuario.

## ```DisponibilidadDAO```

Esta interfaz contendrá las consultas necesarias para conseguir los datos de las disponibilidades de un inmueble.
