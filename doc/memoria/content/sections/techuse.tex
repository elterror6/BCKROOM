\section{Tecnologías Usadas}

En esta sección se describirán las tecnologías utilizadas en el proyecto. Las tecnologías usadas son las siguientes:
\begin{itemize}
    \item \textbf{Maven}. Para gestionar dependencias de manera sencilla.
    \item \textbf{Spring Web}. Para poder realizar una aplicación web.
    \item  \textbf{Spring Security}. Para poder cifrar las contraseñas de los usuarios.
    \item \textbf{Spring JPA}. Para ayudar en operaciones de persistencia en base de datos relacional.
    \item \textbf{Apache Derby}. Como base de datos relacional embebida para no requerir de servidor ni instalación.
\end{itemize}
