\section{Historias de Usuario}

Las historias de usuario de la aplicación Bckroom son las siguientes. Las historias de usuario son la descripción de funcionalidades tal y como la percibe el usuario.

\begin{enumerate}[label=HU\arabic*:]
    \item Como usuario sin iniciar sesión quiero poder buscar alojamientos para poder ver inmuebles sin cuenta.

    \item Como usuario del sistema quiero poder aplicar ciertos filtros para poder buscar alojamientos que se adapten a lo que necesito.

    \item Como usuario sin cuenta quiero poder crearme una cuenta de inquilino para poder guardar inmuebles a una lista de deseados o reservar alojamientos.

    \item Como usuario sin cuenta pero con propiedades quiero poder crearme una cuenta de propietario para poder ofertar para reserva las propiedades.

    \item Como usuario sin iniciar sesión quiero poder iniciar sesión con una cuenta de usuario para poder reservar alojamientos o poder ofertar alojamientos.

    \item Como inquilino quiero poder reservar inmuebles para poder disfrutar del alojamiento.

    \item Como inquilino quiero poder añadir inmuebles a una lista de deseos para poder guardar alojamientos que me gusten.

    \item Como inquilino quiero poder pagar vía tarjeta de crédito, débito o Paypal una reserva para poder completar la reserva de un inmueble.

    \item Como propietario quiero poder dar de alta propiedades para poder ofertarla para ser alquilada.

    \item Como propietario quiero poder indicar si se puede reservar inmediatamente o no un alojamiento para poder guardarse o no el derecho de aceptar o no las solicitudes.
\end{enumerate}
